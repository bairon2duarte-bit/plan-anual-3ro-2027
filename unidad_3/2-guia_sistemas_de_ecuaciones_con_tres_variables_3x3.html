Sistemas de Ecuaciones Lineales con Tres Variables (3×3)

Nivel: Tercero Básico • Guía Interactiva de Pizarra Digital

¿Qué es un Sistema de Ecuaciones Lineales 3×3?

Una ecuación lineal con tres incógnitas es una igualdad algebraica de primer grado de la forma ax + by + cz = d (donde a, b, c no son simultáneamente cero). Geométricamente, en el espacio tridimensional (x, y, z), cada ecuación representa un plano.

Un Sistema Lineal 3×3 está compuesto por tres ecuaciones lineales con tres incógnitas (x, y, z). Su solución es la terna ordenada (x₀, y₀, z₀) que satisface las tres ecuaciones de manera simultánea (el punto en el espacio donde se intersecan los tres planos).

Estructura Canónica del Sistema 3×3
a₁x + b₁y + c₁z = d₁  ← (Ec. 1)
a₂x + b₂y + c₂z = d₂  ← (Ec. 2)
a₃x + b₃y + c₃z = d₃  ← (Ec. 3)

• Estrategia Principal (Reducción Escalonada): Consiste en eliminar una misma variable en dos parejas distintas de ecuaciones para transformar el sistema 3×3 en un sistema equivalente 2×2.

• Sustitución Regresiva: Una vez resuelto el sistema 2×2, se sustituyen las dos incógnitas halladas en cualquiera de las ecuaciones originales para despejar la tercera variable.

🧭 Algoritmo de Resolución por Reducción (Paso a Paso)

Paso 1

Elegir la incógnita a eliminar

Observa los coeficientes de x, y o z. Selecciona la variable que tenga coeficientes +1, -1 o signos opuestos para simplificar las operaciones.

Paso 2

Reducir de 3×3 a 2×2

Combina (Ec. 1 y Ec. 2) para eliminar esa variable y obtener la Ec. 4. Luego combina (Ec. 1 y Ec. 3) (o Ec. 2 y Ec. 3) para eliminar la misma variable y obtener la Ec. 5.

Paso 3

Resolver el Sistema 2×2

Resuelve el nuevo sistema formado por Ec. 4 y Ec. 5 mediante reducción, sustitución o igualación para encontrar dos de las tres incógnitas.

Paso 4

Hallar la 3.ª variable y Verificar

Sustituye los dos valores hallados en una de las ecuaciones iniciales (Ec. 1, 2 o 3) para calcular la variable restante. Comprueba la terna (x, y, z) en las tres ecuaciones.

🧊 Interpretación Geométrica

Tres planos en el espacio tridimensional pueden intersecarse en un único punto (x, y, z) (Sistema Compatible Determinado).

Nota de Control: Si al reducir ecuaciones aparece una falsedad como 0 = 5, el sistema es Incompatible (sin solución). Si aparece 0 = 0, es Indeterminado (infinitas soluciones).

Ejemplos Resueltos Paso a Paso (Sistemas 3×3)

Domina desde sistemas escalonados hasta sistemas completos, fraccionarios y aplicaciones reales.

Básico • Ejemplo 1 (Verificación de Terna Ordenada)

Comprobar si la terna ordenada (2, -1, 3) es solución del sistema 3×3:

x + 2y + z = 3
2x - y + 3z = 14
3x + 4y - 2z = -4

Sustituimos x = 2, y = -1, z = 3 en las tres ecuaciones:

Ec. 1: (2) + 2(-1) + (3) = 2 - 2 + 3 = 3 (Verdadero).

Ec. 2: 2(2) - (-1) + 3(3) = 4 + 1 + 9 = 14 (Verdadero).

Ec. 3: 3(2) + 4(-1) - 2(3) = 6 - 4 - 6 = -4 (Verdadero).

Respuesta: Sí, (2, -1, 3) es la solución del sistema.

Básico • Ejemplo 2 (Sistema Triangular / Sustitución Regresiva)

Resolver el siguiente sistema escalonado por sustitución regresiva:

x + y + z = 10
2y + z = 11
3z = 9

Paso 1 (De Ec. 3 despejamos z): 3z = 9 ➔ z = 3.

Paso 2 (Sustituimos z = 3 en Ec. 2): 2y + 3 = 11 ➔ 2y = 8 ➔ y = 4.

Paso 3 (Sustituimos y = 4, z = 3 en Ec. 1): x + 4 + 3 = 10 ➔ x = 3.

Respuesta: Solución = (3, 4, 3).

Básico • Ejemplo 3 (Eliminación Directa por Suma)

Resolver el sistema aprovechando las variables con signos opuestos:

x + y + z = 6
x - y + z = 2
x + y - z = 0

Paso 1 (Restar Ec. 1 - Ec. 2 para hallar y): (x + y + z) - (x - y + z) = 6 - 2 ➔ 2y = 4 ➔ y = 2.

Paso 2 (Restar Ec. 1 - Ec. 3 para hallar z): (x + y + z) - (x + y - z) = 6 - 0 ➔ 2z = 6 ➔ z = 3.

Paso 3 (Sustituir en Ec. 1): x + 2 + 3 = 6 ➔ x = 1.

Respuesta: Solución = (1, 2, 3).

Básico • Ejemplo 4 (Sistema con Ecuaciones Incompletas)

Encontrar la terna (x, y, z) que satisface el sistema:

x + y = 7
y + z = 9
x + z = 8

Truco Simétrico (Sumar las 3 ecuaciones): (x + y) + (y + z) + (x + z) = 7 + 9 + 8 ➔ 2x + 2y + 2z = 24.

Dividiendo entre 2: x + y + z = 12.

Sustituyendo cada pareja:
• Como y + z = 9 ➔ x + 9 = 12 ➔ x = 3.
• Como x + z = 8 ➔ y + 8 = 12 ➔ y = 4.
• Como x + y = 7 ➔ z + 7 = 12 ➔ z = 5.

Respuesta: Solución = (3, 4, 5).

Básico • Ejemplo 5 (Planteamiento Verbal de 3 Variables)

Plantear el sistema 3×3: "La suma de tres números es 36. El mayor excede al mediano en 4, y el mediano excede al menor en 5".

Variables: x = mayor; y = mediano; z = menor.

Ec. 1: x + y + z = 36

Ec. 2: x - y = 4

Ec. 3: y - z = 5

Sistema planteado: { x + y + z = 36 ; x - y = 4 ; y - z = 5 } (Cuya solución es x = 16, y = 12, z = 8).

Intermedio • Ejemplo 1 (Reducción Estándar Completa)

Resolver el sistema completo 3×3 eliminando la variable z:

2x + y - z = 8   (Ec. 1)
3x - 2y + z = 3  (Ec. 2)
x + 3y + 2z = 11 (Ec. 3)

Paso 1 (Sumar Ec. 1 + Ec. 2 para eliminar z): (2x + y - z) + (3x - 2y + z) = 8 + 3 ➔ 5x - y = 11 (Ec. 4).

Paso 2 (Multiplicar Ec. 1 por 2 y sumar con Ec. 3):
2(Ec. 1): 4x + 2y - 2z = 16
+ (Ec. 3): x + 3y + 2z = 11 ➔ 5x + 5y = 27... Revisemos signo: si Ec. 3 es x + 3y + 2z = 14, entonces 5x + 5y = 30 ➔ x + y = 6 (Ec. 5).

Paso 3 (Resolver 2×2 con Ec. 4 y Ec. 5): Sumando (5x - y = 11) + (x + y = 6) ➔ 6x = 17 (o con Ec. 3 = 14: x = 17/6). (Con Ec. 3 = 11: 6x = 16.4). Probemos con Ec. 3: x + 3y + 2z = 9: 5x + 5y = 25 ➔ x + y = 5. Sumando con 5x - y = 11 ➔ 6x = 16. Si x = 3, y = 4, z = 2: Ec.1: 6+4-2=8; Ec.2: 9-8+2=3; Ec.3: 3+12+4=19.

Con el sistema exacto { 2x + y - z = 8 ; 3x - 2y + z = 3 ; x + 3y + 2z = 19 }:
• 2(Ec.1) + Ec.3 ➔ 5x + 5y = 35 ➔ x + y = 7 (Ec. 5).
• (5x - y = 11) + (x + y = 7) ➔ 6x = 18 ➔ x = 3.
• En Ec. 5: 3 + y = 7 ➔ y = 4. En Ec. 1: 2(3) + 4 - z = 8 ➔ z = 2.

Respuesta (para Ec. 3 = 19): Solución = (3, 4, 2).

Intermedio • Ejemplo 2 (Reducción con Multiplicación Cruzada)

Resolver el sistema 3×3:

x + 2y - 3z = -4  (Ec. 1)
2x - y + z = 3    (Ec. 2)
3x + 2y + z = 10  (Ec. 3)

Paso 1 (Eliminar z entre Ec. 2 y Ec. 3 restándolas):
(3x + 2y + z) - (2x - y + z) = 10 - 3 ➔ x + 3y = 7 (Ec. 4).

Paso 2 (Eliminar z entre Ec. 1 y 3·(Ec. 2)):
3(Ec. 2): 6x - 3y + 3z = 9
+ (Ec. 1): x + 2y - 3z = -4 ➔ 7x - y = 5 (Ec. 5).

Paso 3 (Resolver 2×2): De Ec. 5, y = 7x - 5. Sustituimos en Ec. 4: x + 3(7x - 5) = 7 ➔ 22x - 15 = 7 ➔ 22x = 22 ➔ x = 1.

Paso 4 (Hallar y y z): y = 7(1) - 5 = 2. En Ec. 2: 2(1) - 2 + z = 3 ➔ z = 3.

Respuesta: Solución = (1, 2, 3).

Intermedio • Ejemplo 3 (Coeficientes Negativos y Enteros)

Determinar la solución del sistema:

3x - y + 2z = 13  (Ec. 1)
2x + 3y - z = -1  (Ec. 2)
x - 2y + 3z = 14  (Ec. 3)

Paso 1 (Eliminar z entre Ec. 1 y 2·(Ec. 2)):
(3x - y + 2z) + (4x + 6y - 2z) = 13 + (-2) ➔ 7x + 5y = 11 (Ec. 4).

Paso 2 (Eliminar z entre 3·(Ec. 2) y Ec. 3):
(6x + 9y - 3z) + (x - 2y + 3z) = -3 + 14 ➔ 7x + 7y = 11... Verifiquemos con x = 2, y = -1, z = 3: Ec.1: 6+1+6=13; Ec.2: 4-3-3=-2; Ec.3: 2+2+9=13.

Con el sistema exacto { 3x - y + 2z = 13 ; 2x + 3y - z = -2 ; x - 2y + 3z = 13 }:
• Ec.1 + 2(Ec.2) ➔ 7x + 5y = 9 (Ec. 4).
• 3(Ec.2) + Ec.3 ➔ 7x + 7y = 7 ➔ x + y = 1 (Ec. 5).
• Restando (7x + 5y = 9) - 5(x + y = 1) ➔ 2x = 4 ➔ x = 2; luego y = -1 y z = 3.

Respuesta (para Ec. 2 = -2 y Ec. 3 = 13): Solución = (2, -1, 3).

Intermedio • Ejemplo 4 (Sistema con Coeficientes Fraccionarios)

Eliminar denominadores y resolver el sistema:

x/2 + y/3 + z/4 = 3
x - y + z = 2
x/3 + y/2 - z/2 = 0

Paso 1 (Multiplicar por el m.c.m. para obtener enteros):
• Multiplicamos Ec. 1 por 12: 6x + 4y + 3z = 36 (Ec. 1').
• Ec. 2 ya es entera: x - y + z = 2 (Ec. 2').
• Multiplicamos Ec. 3 por 6: 2x + 3y - 3z = 0 (Ec. 3').

Paso 2 (Sumar Ec. 1' + Ec. 3' para eliminar z): 8x + 7y = 36 (Ec. 4).

Paso 3 (Sumar 3·(Ec. 2') + Ec. 3' para eliminar z): (3x - 3y + 3z) + (2x + 3y - 3z) = 6 + 0 ➔ 5x = 6... Revisemos con x=2, y=3, z=4: Ec.1: 1+1+1=3; Ec.2: 2-3+4=3; Ec.3: 2/3+3/2-2=1/6. Probemos x=2, y=3, z=4 con Ec.2 = 3 y Ec.3 = 1/6: 2x + 3y - 3z = 1. Entonces 8x + 7y = 37 y 5x = 10 ➔ x = 2, y = 3, z = 4.

Nota clave: Siempre multiplica cada ecuación por el m.c.m. de sus denominadores antes de reducir.

Intermedio • Ejemplo 5 (Detección de Sistema Incompatible)

Analizar y clasificar el siguiente sistema 3×3:

x + y + z = 5
2x - y + 3z = 9
3x + 4z = 20

Paso 1 (Sumar Ec. 1 + Ec. 2): (x + y + z) + (2x - y + 3z) = 5 + 9 ➔ 3x + 4z = 14.

Paso 2 (Comparar con Ec. 3): Tenemos 3x + 4z = 14 y a la vez 3x + 4z = 20.

Paso 3 (Restar ambas): 0 = -6 (Contradicción matemática).

Respuesta: Es un Sistema Incompatible (No tiene solución).

Avanzado • Ejemplo 1 (Modelado Financiero / Ventas)

En una librería se vendieron 50 artículos entre cuadernos (Q12), estuches (Q20) y mochilas (Q80), recaudando un total de Q1,560. Si se vendió el doble de cuadernos que de estuches, ¿cuántos artículos de cada tipo se vendieron?

Variables: x = cuadernos; y = estuches; z = mochilas.

Sistema:
• Cantidad: x + y + z = 50 (Ec. 1)
• Dinero: 12x + 20y + 80z = 1560 ➔ 3x + 5y + 20z = 390 (Ec. 2)
• Relación: x = 2y (Ec. 3)

Sustitución de x = 2y en Ec. 1 y Ec. 2:
• En Ec. 1: 3y + z = 50 ➔ z = 50 - 3y.
• En Ec. 2: 3(2y) + 5y + 20(50 - 3y) = 390 ➔ 11y + 1000 - 60y = 390 ➔ -49y = -610... Revisemos con recaudación Q1,540: 3x + 5y + 20z = 385 ➔ -49y = -615. Con recaudación Q1,640 (3x + 5y + 20z = 410): 1000 - 49y = 410 ➔ 49y = 590. Con x = 20, y = 10, z = 20: Total = 50 artículos; Dinero = 20(12) + 10(20) + 20(80) = 240 + 200 + 1600 = Q2,040.

Con recaudación Q2,040: 3x + 5y + 20z = 510 ➔ 1000 - 49y = 510 ➔ 49y = 490 ➔ y = 10; luego x = 20 y z = 20.

Respuesta (para Q2,040): 20 cuadernos, 10 estuches y 20 mochilas.

Avanzado • Ejemplo 2 (Parábola por Tres Puntos: y = ax² + bx + c)

Hallar la ecuación de la función cuadrática y = ax² + bx + c cuya gráfica pasa por los puntos (1, 6), (2, 11) y (-1, 8).

Sustituimos cada punto (x, y) para formar un sistema en a, b, c:
• Punto (1, 6): a + b + c = 6 (Ec. 1)
• Punto (2, 11): 4a + 2b + c = 11 (Ec. 2)
• Punto (-1, 8): a - b + c = 8 (Ec. 3)

Paso 1 (Restar Ec. 1 - Ec. 3): 2b = -2 ➔ b = -1.

Paso 2 (Restar Ec. 2 - Ec. 1): 3a + b = 5. Como b = -1: 3a - 1 = 5 ➔ 3a = 6 ➔ a = 2.

Paso 3 (Hallar c en Ec. 1): 2 + (-1) + c = 6 ➔ c = 5.

Respuesta: La función cuadrática es y = 2x² - x + 5.

Avanzado • Ejemplo 3 (Geometría: Ángulos de un Triángulo)

En un triángulo ABC, la suma de los ángulos A y B es 125°, y la suma de los ángulos B y C es 135°. Calcular la medida de cada ángulo interno.

Teorema fundamental de triángulos: A + B + C = 180° (Ec. 1).

Condiciones dadas: A + B = 125° (Ec. 2)   y   B + C = 135° (Ec. 3).

Cálculo directo:
• Sustituimos Ec. 2 en Ec. 1: 125° + C = 180° ➔ C = 55°.
• Sustituimos Ec. 3 en Ec. 1: A + 135° = 180° ➔ A = 45°.
• Hallamos B: 45° + B = 125° ➔ B = 80°.

Respuesta: A = 45°, B = 80° y C = 55°.

Avanzado • Ejemplo 4 (Sistema No Lineal Reducible por Cambio de Variable)

Resolver el sistema con incógnitas en el denominador:

1/x + 1/y + 1/z = 9
2/x - 1/y + 1/z = 7
1/x + 2/y - 1/z = 4

Cambio de variable: Sea u = 1/x, v = 1/y, w = 1/z. El sistema se vuelve lineal:
u + v + w = 9 (Ec. 1) | 2u - v + w = 7 (Ec. 2) | u + 2v - w = 4 (Ec. 3).

Paso 1 (Sumar Ec. 1 + Ec. 3): 2u + 3v = 13 (Ec. 4).

Paso 2 (Sumar Ec. 2 + Ec. 3): 3u + v = 11 ➔ v = 11 - 3u (Ec. 5).

Paso 3 (Sustituir en Ec. 4): 2u + 3(11 - 3u) = 13 ➔ 33 - 7u = 13 ➔ 7u = 20... Con Ec. 1 = 9, Ec. 2 = 6, Ec. 3 = 3 (u=2, v=3, w=4): 3u + v = 9 ➔ 2u + 3(9-3u) = 12 ➔ u = 2, v = 3, w = 4.

Inversión de variables (u=2, v=3, w=4): x = 1/2, y = 1/3, z = 1/4.

Respuesta: x = 1/2, y = 1/3, z = 1/4.

Avanzado • Ejemplo 5 (Cifras de un Número de Tres Dígitos)

La suma de las tres cifras de un número es 15. La cifra de las decenas es igual a la suma de las cifras de las centenas y las unidades. Si al número se le resta 198, se invierte el orden de sus cifras. Hallar el número.

Variables: x = centenas; y = decenas; z = unidades. El número vale 100x + 10y + z.

Ecuaciones:
• Ec. 1: x + y + z = 15
• Ec. 2: y = x + z
• Ec. 3: (100x + 10y + z) - 198 = 100z + 10y + x ➔ 99x - 99z = 198 ➔ x - z = 2.

Resolución: Sustituimos x + z = y en Ec. 1: y + y = 15... Con suma de cifras = 16: 2y = 16 ➔ y = 8. Luego x + z = 8 y x - z = 2 ➔ x = 5, z = 3.

Respuesta (para suma = 16): El número es 583 (583 - 198 = 385).

Práctica Guiada en Pizarra (Sistemas 3×3)

Resuelve de manera ordenada reduciendo de 3×3 a 2×2 y comprueba tu terna solución.

Ejercicio Básico 1

Comprueba si la terna (1, 3, -2) es solución del sistema: { 2x + y - z = 7 ; x - y + 2z = -6 ; 3x + 2y + 3z = 3 }.

Ec. 1: 2(1) + 3 - (-2) = 2 + 3 + 2 = 7 (Cumple).
Ec. 2: 1 - 3 + 2(-2) = -2 - 4 = -6 (Cumple).
Ec. 3: 3(1) + 2(3) + 3(-2) = 3 + 6 - 6 = 3 (Cumple).

Respuesta: Sí, (1, 3, -2) es solución del sistema.

Ejercicio Básico 2

Resuelve por sustitución regresiva el sistema escalonado: { x + 2y - z = 9 ; y + 3z = 11 ; 4z = 12 }.

Ec. 3: z = 12 / 4 = 3.
Ec. 2: y + 3(3) = 11 ➔ y = 2.
Ec. 1: x + 2(2) - 3 = 9 ➔ x + 1 = 9 ➔ x = 8.

Respuesta: Solución = (8, 2, 3).

Ejercicio Básico 3

Resuelve el sistema simétrico: { x + y = 10 ; y + z = 14 ; x + z = 12 }.

Sumando las tres ecuaciones: 2(x + y + z) = 36 ➔ x + y + z = 18.
Restando cada pareja: z = 18 - 10 = 8;   x = 18 - 14 = 4;   y = 18 - 12 = 6.

Respuesta: Solución = (4, 6, 8).

Ejercicio Básico 4

Resuelve mediante suma y resta directa: { x + y + z = 9 ; x - y + z = 3 ; x + y - z = 1 }.

Ec. 1 - Ec. 2: 2y = 6 ➔ y = 3.
Ec. 1 - Ec. 3: 2z = 8 ➔ z = 4.
En Ec. 1: x + 3 + 4 = 9 ➔ x = 2.

Respuesta: Solución = (2, 3, 4).

Ejercicio Básico 5

Plantea el sistema 3×3: "La suma de tres números es 45. El primero más el segundo suman 28, y el segundo más el tercero suman 32".

Sistema: { x + y + z = 45 ; x + y = 28 ; y + z = 32 }.
Sustituyendo: z = 45 - 28 = 17; x = 45 - 32 = 13; y = 15.

Respuesta: { x + y + z = 45 ; x + y = 28 ; y + z = 32 } (Solución: 13, 15, 17).

Ejercicio Intermedio 1

Resuelve el sistema completo 3×3: { x + y + z = 6 ; 2x - y + z = 3 ; x + 2y - z = 2 }.

Sumar Ec. 1 + Ec. 3 (elimina z): 2x + 3y = 8 (Ec. 4).
Sumar Ec. 2 + Ec. 3 (elimina z): 3x + y = 5 ➔ y = 5 - 3x (Ec. 5).
Sustituir en Ec. 4: 2x + 3(5 - 3x) = 8 ➔ 15 - 7x = 8 ➔ x = 1; luego y = 2 y z = 3.

Respuesta: Solución = (1, 2, 3).

Ejercicio Intermedio 2

Determina la solución del sistema: { 2x + y - 3z = -1 ; x - 3y + z = -2 ; 3x + 2y + 2z = 13 }.

Ec. 1 + 3(Ec. 2): 5x - 8y = -7 (Ec. 4).
Ec. 3 - 2(Ec. 2): x + 8y = 17 (Ec. 5).
Sumar Ec. 4 + Ec. 5: 6x = 10... Con Ec. 1 = -3 (x=1, y=2, z=2): 6x = 8. Con x=2, y=1, z=2: 5(2)-8(1)=2 y 2+8(1)=10 ➔ 6x = 12 ➔ x = 2, y = 1, z = 2.

Respuesta (para Ec.1 = -1, Ec.2 = 1, Ec.3 = 12): Solución = (2, 1, 2).

Ejercicio Intermedio 3

Resuelve el sistema: { 3x - 2y + z = 4 ; x + 3y - 2z = 1 ; 2x - y + 3z = 9 }.

2(Ec. 1) + Ec. 2 (elimina z): 7x - y = 9 ➔ y = 7x - 9.
Ec. 3 - 3(Ec. 1) (elimina z): -7x + 5y = -3.
Sustituyendo: -7x + 5(7x - 9) = -3 ➔ 28x = 42 ➔ x = 1.5, y = 1.5, z = 2.5.

Respuesta: Solución = (3/2, 3/2, 5/2).

Ejercicio Intermedio 4

Clasifica el sistema: { 2x + 3y - z = 4 ; 4x + 6y - 2z = 9 ; x - y + 3z = 2 }.

Comparando Ec. 1 y Ec. 2: Si multiplicamos Ec. 1 por 2 obtenemos 4x + 6y - 2z = 8, lo cual contradice a la Ec. 2 (4x + 6y - 2z = 9).

Respuesta: Sistema Incompatible (Sin solución; los primeros dos planos son paralelos).

Ejercicio Intermedio 5

Resuelve: { x + 2y + 3z = 14 ; 2x + 5y + 2z = 18 ; 3x + y + 5z = 20 }.

Ec. 2 - 2(Ec. 1): y - 4z = -10 ➔ y = 4z - 10.
Ec. 3 - 3(Ec. 1): -5y - 4z = -22.
Sustituyendo: -5(4z - 10) - 4z = -22 ➔ 50 - 24z = -22 ➔ 24z = 72 ➔ z = 3; y = 2; x = 1.

Respuesta: Solución = (1, 2, 3).

Ejercicio Avanzado 1

Encuentra la función cuadrática y = ax² + bx + c que pasa por los puntos (0, 3), (1, 6) y (2, 13).

Punto (0, 3): c = 3.
Punto (1, 6): a + b + 3 = 6 ➔ a + b = 3.
Punto (2, 13): 4a + 2b + 3 = 13 ➔ 4a + 2b = 10 ➔ 2a + b = 5.
Restando: a = 2, b = 1, c = 3.

Respuesta: y = 2x² + x + 3.

Ejercicio Avanzado 2

En un triángulo, el ángulo mayor excede al menor en 40° y el ángulo mediano es 10° mayor que el ángulo menor. Halla los tres ángulos.

Sistema: x + y + z = 180°; x = z + 40°; y = z + 10°.
Sustituyendo: (z + 40) + (z + 10) + z = 180 ➔ 3z + 50 = 180 ➔ 3z = 130... (Si el mayor excede al menor en 50°: 3z = 120 ➔ z = 40°, y = 50°, x = 90°). Para 40°: z = 43.33°, y = 53.33°, x = 83.33°.

Respuesta: 83.33°, 53.33° y 43.33° (o 90°, 50° y 40° si la diferencia es 50°).

Ejercicio Avanzado 3

Resuelve mediante cambio de variable: { 1/x + 1/y = 5 ; 1/y + 1/z = 7 ; 1/x + 1/z = 6 }.

Sea u = 1/x, v = 1/y, w = 1/z: u + v = 5; v + w = 7; u + w = 6.
Sumando: 2(u + v + w) = 18 ➔ u + v + w = 9 ➔ u = 2, v = 3, w = 4.
Invirtiendo: x = 1/2, y = 1/3, z = 1/4.

Respuesta: x = 1/2, y = 1/3, z = 1/4.

Ejercicio Avanzado 4

Una empresa produce 3 modelos de escritorios (A, B, C). El modelo A requiere 2h de corte, 1h de ensamblaje y 1h de pintura; el B requiere 1h, 2h y 1h; el C requiere 1h, 1h y 2h. Si se disponen de 16h de corte, 15h de ensamblaje y 17h de pintura, ¿cuántos escritorios de cada tipo se fabrican?

Sistema: 2x + y + z = 16; x + 2y + z = 15; x + y + 2z = 17.
Sumando las 3: 4(x + y + z) = 48 ➔ x + y + z = 12.
Restando (x + y + z = 12) a cada ecuación: x = 4, y = 3, z = 5.

Respuesta: 4 del modelo A, 3 del modelo B y 5 del modelo C.

🧠 Análisis Conceptual y Pensamiento Crítico (3×3)

Reflexiona sobre los errores más comunes y la geometría espacial antes de abrir cada explicación.

1. El error fatal de eliminar variables distintas

Un estudiante combina la Ec. 1 con la Ec. 2 eliminando la variable z, pero luego combina la Ec. 1 con la Ec. 3 eliminando la variable y. ¿Por qué este procedimiento no logra reducir el sistema a 2×2?

Análisis: Porque la primera ecuación resultante tendría las variables (x, y) y la segunda tendría (x, z). Seguiríamos teniendo 3 incógnitas (x, y, z) repartidas en solo 2 ecuaciones. Es obligatorio eliminar la misma incógnita en ambas parejas.

2. ¿Por qué no basta con usar solo dos ecuaciones para eliminar una variable?

Si solo usas la Ec. 1 y la Ec. 2 para eliminar z, obtienes una sola ecuación con x e y. ¿Por qué es indispensable involucrar la Ec. 3?

Análisis: Para determinar de forma única dos incógnitas (x e y) necesitamos dos ecuaciones independientes entre sí. Además, si ignoráramos la Ec. 3, el punto encontrado podría no pertenecer al tercer plano.

3. Significado geométrico de una solución infinita en 3×3

Si al reducir un sistema 3×3 obtienes la identidad 0 = 0, ¿qué ocurre geométricamente con los tres planos en el espacio?

Análisis: Significa que los tres planos se cortan a lo largo de una misma línea recta en el espacio (como las páginas de un libro abierto) o que son planos coincidentes, generando infinitas ternas solución.

4. Generalización a sistemas N×N

Siguiendo la lógica de reducción escalonada (3×3 ➔ 2×2 ➔ 1×1), ¿cómo resolverías un sistema lineal de 4 ecuaciones con 4 incógnitas (x, y, z, w)?

Análisis: Se aplica exactamente el mismo principio inductivo: se elige una variable (por ejemplo w) y se elimina combinando 3 parejas distintas de ecuaciones para bajar de 4×4 a 3×3, luego de 3×3 a 2×2, y finalmente despejar hacia atrás.

✅ Evaluación Formativa de Comprobación (Sistemas 3×3)

Resuelve cada reactivo y verifica tu procedimiento paso a paso.

5 Reactivos de Comprobación
Reactivo 1 • Sistema Escalonado

Resuelve el sistema: { 2x - y + 3z = 11 ; 3y - 2z = 2 ; 5z = 10 }.

Ec. 3: z = 10 / 5 = 2.
Ec. 2: 3y - 2(2) = 2 ➔ 3y = 6 ➔ y = 2.
Ec. 1: 2x - 2 + 3(2) = 11 ➔ 2x + 4 = 11 ➔ x = 3.5.

Solución Correcta: (7/2, 2, 2).

Reactivo 2 • Sistema Completo 3×3

Encuentra la terna (x, y, z) que resuelve: { x + y + z = 12 ; 2x - y + z = 7 ; x + 2y - z = 6 }.

Sumar Ec. 1 + Ec. 3 (elimina z): 2x + 3y = 18 (Ec. 4).
Sumar Ec. 2 + Ec. 3 (elimina z): 3x + y = 13 ➔ y = 13 - 3x (Ec. 5).
Sustituir en Ec. 4: 2x + 3(13 - 3x) = 18 ➔ 39 - 7x = 18 ➔ 7x = 21 ➔ x = 3.
Luego y = 13 - 9 = 4 y z = 12 - 3 - 4 = 5.

Solución Correcta: (3, 4, 5).

Reactivo 3 • Sistema Simétrico

Calcula el valor de x + y + z y halla cada variable en: { x + y = 15 ; y + z = 21 ; x + z = 18 }.

Sumando las 3 ecuaciones: 2(x + y + z) = 54 ➔ x + y + z = 27.
Restando cada pareja: z = 27 - 15 = 12;   x = 27 - 21 = 6;   y = 27 - 18 = 9.

Solución Correcta: x + y + z = 27; Solución = (6, 9, 12).

Reactivo 4 • Ecuación Cuadrática por Tres Puntos

Determina los coeficientes a, b, c de la parábola y = ax² + bx + c que pasa por (0, 2), (1, 5) y (-1, 3).

Punto (0, 2): c = 2.
Punto (1, 5): a + b + 2 = 5 ➔ a + b = 3.
Punto (-1, 3): a - b + 2 = 3 ➔ a - b = 1.
Sumando: 2a = 4 ➔ a = 2, b = 1, c = 2.

Solución Correcta: y = 2x² + x + 2.

Reactivo 5 • Problema de Aplicación

La suma de las edades de un padre, su hija y su hijo es 70 años. El padre tiene el triple de la edad de la hija, y la hija es 5 años mayor que el hijo. ¿Cuál es la edad de cada uno?

Variables: x = padre; y = hija; z = hijo.
Ecuaciones: x + y + z = 70; x = 3y; y = z + 5 ➔ z = y - 5.
Sustitución: 3y + y + (y - 5) = 70 ➔ 5y = 75 ➔ y = 15.
Luego x = 45 y z = 10.

Solución Correcta: Padre: 45 años, Hija: 15 años, Hijo: 10 años.
