Fundamentos de Teoría de Conjuntos

Conjunto: Colección bien definida de objetos. Se representa con letras mayúsculas (A, B, C).

Elemento: Cada objeto que forma parte de un conjunto.

Pertenencia: Si x es elemento de A, escribimos x ∈ A; si no pertenece, x ∉ A.

Conjunto finito: Cantidad limitada de elementos.

Conjunto infinito: Cantidad ilimitada de elementos.

Conjunto vacío: No contiene elementos. Se representa por ∅ o { }.

Formas de representar conjuntos

Forma Descripción Ejemplo
Por extensión Se enumeran los elementos entre llaves. A = {a, e, i, o, u}
Por comprensión Se indica la propiedad o regla que cumplen. A = {x | x es una vocal}
Verbal Se describe con palabras la característica común. A es el conjunto de las vocales.

Ejemplo guiado

Sea B = {2, 4, 6, 8, 10}

  • Pertenencia: 4 ∈ B (verdadero) y 7 ∉ B (verdadero, porque 7 no está).
  • Tipo: El conjunto B es finito porque tiene exactamente cinco elementos.
  • Por comprensión: B = {x ∈ ℕ | x es par y 2 ≤ x ≤ 10}

Verificación Individual

  3. Explica por qué "los estudiantes altos" puede ser una regla imprecisa si no se establece una medida.

Solución esperada:

  1. Ejemplo: rojo ∈ C ; verde ∉ C.
  2. N = {1, 2, 3, 4}
  3. Porque la altura es relativa; lo que es "alto" para una persona puede no serlo para otra. No está bien definido.
