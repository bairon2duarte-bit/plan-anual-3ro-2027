1. Fundamentación Teórica: Ecuaciones de Segundo Grado

Estructura general, clasificación, métodos algebraicos de resolución, discriminante y propiedades de las raíces.

Forma Estándar y Elementos

Grado 2

Una ecuación cuadrática (o de segundo grado) con una incógnita \(x\) es toda ecuación que puede reducirse a la forma estándar:

\[ax^2 + bx + c = 0 \qquad (a \neq 0)\]
  • • \(ax^2\): Término cuadrático (\(a\) es el coeficiente principal).
  • • \(bx\): Término lineal (\(b\) es el coeficiente lineal).
  • • \(c\): Término independiente o constante.
  • • Raíces o soluciones: Valores \(x_1\) y \(x_2\) que anulan el polinomio cuadrático al sustituirse.

Clasificación de Ecuaciones Cuadráticas

Estructura
  • • Ecuación Completa (\(b \neq 0,\; c \neq 0\)): Contiene los tres términos. Ejemplo: \(2x^2 - 5x - 3 = 0\).
  • • Incompleta Pura (\(b = 0\)): Tiene la forma \(ax^2 + c = 0\). Se resuelve despejando \(x^2\) y extrayendo raíz cuadrada (\(x = \pm\sqrt{-c/a}\)).
  • • Incompleta Mixta (\(c = 0\)): Tiene la forma \(ax^2 + bx = 0\). Se resuelve extrayendo factor común \(x(ax + b) = 0\), por lo que una raíz siempre es \(x_1 = 0\).

Los Cuatro Métodos de Resolución Algebraica

Estrategias

1. Despeje Directo (Raíz Cuadrada)

Aplicable cuando \(b = 0\) o cuando la ecuación tiene la forma \((x - h)^2 = k\).

Propiedad: \(u^2 = k \iff u = \pm\sqrt{k}\) (para \(k \ge 0\)).

2. Factorización (Propiedad del Producto Cero)

Se expresa \(ax^2 + bx + c = 0\) como producto de dos factores lineales \((px + q)(rx + s) = 0\).

Principio: \(A \cdot B = 0 \iff A = 0 \;\text{o}\; B = 0\).

3. Completación de Cuadrados (TCP)

Dividir entre \(a\), aislar el término independiente y sumar \(\left(\frac{b}{2a}\right)^2\) en ambos miembros para formar un binomio al cuadrado.

Base teórica para deducir la fórmula general.

4. Fórmula General Cuadrática

Válida para toda ecuación cuadrática con coeficientes reales:

\[x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\]

El Discriminante (\(\Delta\)) y Teorema de Vieta

La expresión bajo el radical \(\mathbf{\Delta = b^2 - 4ac}\) determina la naturaleza de las raíces sin necesidad de resolver la ecuación:

• Si \(\Delta > 0\): Dos raíces reales y distintas (\(x_1 \neq x_2\)). La parábola corta al eje \(X\) en dos puntos.

• Si \(\Delta = 0\): Una raíz real doble o repetida (\(x_1 = x_2 = -\frac{b}{2a}\)). La parábola es tangente al eje \(X\).

• Si \(\Delta < 0\): No existen raíces reales (dos soluciones complejas conjugadas). La parábola no toca el eje \(X\).

Relaciones de Vieta (Suma y Producto de Raíces):

\[x_1 + x_2 = -\frac{b}{a} \qquad\text{y}\qquad x_1 \cdot x_2 = \frac{c}{a}\]

Interpretación Geométrica del Discriminante (\(\Delta\))

Las soluciones reales de \(ax^2 + bx + c = 0\) son las abscisas donde la parábola \(y = ax^2 + bx + c\) interseca al eje \(X\).

2. Ejemplos Resueltos Paso a Paso

Aplicación rigurosa de los cuatro métodos algebraicos y modelación de problemas cuadráticos.

Ejemplo 1 — Método de Factorización Trinomio \(ax^2+bx+c\)

Resolver: \(3x^2 - 11x - 4 = 0\)

1. Descomponemos el término central (dos números que multipliquen \(3(-4) = -12\) y sumen \(-11\): son \(-12\) y \(+1\)):
\(3x^2 - 12x + x - 4 = 0\)

2. Agrupamos y factorizamos: \(3x(x - 4) + 1(x - 4) = 0 \implies (x - 4)(3x + 1) = 0\)

3. Igualamos cada factor a cero:
\(x - 4 = 0 \implies \mathbf{x_1 = 4}\)  |  \(3x + 1 = 0 \implies \mathbf{x_2 = -\dfrac{1}{3}}\)

Ejemplo 2 — Completación de Cuadrados TCP

Resolver completando el cuadrado: \(x^2 + 6x - 16 = 0\)

1. Transponemos el término independiente: \(x^2 + 6x = 16\)

2. Sumamos \(\left(\frac{6}{2}\right)^2 = 3^2 = 9\) en ambos miembros:
\(x^2 + 6x + 9 = 16 + 9 \implies (x + 3)^2 = 25\)

3. Extraemos raíz cuadrada y despejamos: \(x + 3 = \pm 5\)
\(\mathbf{x_1 = -3 + 5 = 2}\)  |  \(\mathbf{x_2 = -3 - 5 = -8}\)

Ejemplo 3 — Fórmula General Cuadrática Raíces Irracionales

Resolver: \(2x^2 - 4x - 3 = 0\)

1. Identificamos coeficientes: \(a = 2,\; b = -4,\; c = -3\).

2. Calculamos el discriminante: \(\Delta = (-4)^2 - 4(2)(-3) = 16 + 24 = 40 > 0\).

3. Aplicamos la fórmula y simplificamos el radical (\(\sqrt{40} = 2\sqrt{10}\)):
\(x = \dfrac{-(-4) \pm \sqrt{40}}{2(2)} = \dfrac{4 \pm 2\sqrt{10}}{4} = \mathbf{\dfrac{2 \pm \sqrt{10}}{2}}\)

Ejemplo 4 — Aplicación Geométrica (Área) Modelación

El largo de un terreno rectangular mide \(5\text{ m}\) más que su ancho. Si su área es \(176\text{ m}^2\), determina sus dimensiones.

1. Incógnita: Sea \(x\) el ancho (en m); largo \(= x + 5\).

2. Planteamiento (\(A = l \cdot a\)): \(x(x + 5) = 176 \implies x^2 + 5x - 176 = 0\)

3. Factorización: \((x + 16)(x - 11) = 0 \implies x_1 = -16,\; x_2 = 11\).

4. Interpretación: Descartamos \(x = -16\) por ser longitud. \(\mathbf{\text{Ancho: 11 m; Largo: 16 m}}\) (\(11 \times 16 = 176\text{ m}^2\)).

3. Ejercicios Propuestos por Niveles

Desarrolla los procedimientos completos en tu cuaderno y verifica con el solucionario interactivo.

Nivel I. Ecuaciones Incompletas y Factorización

Ejercicio 1 — Incompleta Pura

Resuelve: \(\;4x^2 - 49 = 0\)

Procedimiento:
• \(4x^2 = 49 \implies x^2 = \frac{49}{4} \implies x = \pm\sqrt{\frac{49}{4}} \implies \mathbf{x_1 = \dfrac{7}{2},\quad x_2 = -\dfrac{7}{2}}\).
Ejercicio 2 — Incompleta Mixta

Resuelve: \(\;5x^2 + 15x = 0\)

Procedimiento:
• Factor común \(5x\): \(5x(x + 3) = 0 \implies 5x = 0\) o \(x + 3 = 0\).
• Soluciones: \(\mathbf{x_1 = 0,\quad x_2 = -3}\).
Ejercicio 3 — Factorización \(x^2 + bx + c = 0\)

Resuelve: \(\;x^2 - 9x + 18 = 0\)

Procedimiento:
• Buscamos dos números que multipliquen \(+18\) y sumen \(-9\): son \(-6\) y \(-3\).
• \((x - 6)(x - 3) = 0 \implies \mathbf{x_1 = 6,\quad x_2 = 3}\).
Ejercicio 4 — Factorización \(ax^2 + bx + c = 0\)

Resuelve: \(\;6x^2 + 7x - 3 = 0\)

Procedimiento:
• \(6x^2 + 9x - 2x - 3 = 0 \implies 3x(2x + 3) - 1(2x + 3) = 0 \implies (2x + 3)(3x - 1) = 0\).
• Soluciones: \(\mathbf{x_1 = -\dfrac{3}{2},\quad x_2 = \dfrac{1}{3}}\).

Nivel II. Completación de Cuadrados, Fórmula General y Discriminante

Ejercicio 5 — Completación de Cuadrados

Resuelve completando el cuadrado: \(\;x^2 - 8x + 7 = 0\)

Procedimiento:
• \(x^2 - 8x = -7 \implies x^2 - 8x + 16 = -7 + 16 \implies (x - 4)^2 = 9\)
• \(x - 4 = \pm 3 \implies \mathbf{x_1 = 7,\quad x_2 = 1}\).
Ejercicio 6 — Fórmula General

Resuelve mediante la fórmula general: \(\;3x^2 - 5x - 1 = 0\)

Procedimiento:
• \(a = 3,\; b = -5,\; c = -1 \implies \Delta = (-5)^2 - 4(3)(-1) = 25 + 12 = 37\).
• \(x = \dfrac{5 \pm \sqrt{37}}{2(3)} = \mathbf{\dfrac{5 \pm \sqrt{37}}{6}}\).
Ejercicio 7 — Reducción a Forma Estándar

Reduce a la forma \(ax^2 + bx + c = 0\) y resuelve: \(\;(2x - 1)(x + 3) = x^2 + 7\)

Procedimiento:
• Desarrollamos: \(2x^2 + 5x - 3 = x^2 + 7 \implies x^2 + 5x - 10 = 0\).
• Fórmula general (\(a = 1,\; b = 5,\; c = -10\)): \(\Delta = 25 - 4(1)(-10) = 65\).
• Soluciones: \(\mathbf{x = \dfrac{-5 \pm \sqrt{65}}{2}}\).
Ejercicio 8 — Análisis del Discriminante

Determina el valor de \(k\) para que la ecuación \(4x^2 + kx + 9 = 0\) tenga exactamente una raíz real doble (\(\Delta = 0\)).

Procedimiento:
• Condición de raíz doble: \(\Delta = b^2 - 4ac = 0 \implies k^2 - 4(4)(9) = 0\)
• \(k^2 - 144 = 0 \implies k^2 = 144 \implies \mathbf{k = 12 \;\text{o}\; k = -12}\).

Nivel III. Aplicaciones y Modelación Cuadrática

Ejercicio 9 — Números Consecutivos

El producto de dos números enteros positivos consecutivos es \(240\). Determina cuáles son los dos números.

Modelación y solución:
• Sea \(x\) el primer entero positivo; el consecutivo es \(x + 1\).
• Ecuación: \(x(x + 1) = 240 \implies x^2 + x - 240 = 0 \implies (x + 16)(x - 15) = 0\).
• Como se piden enteros positivos, \(x = 15\). Los números son \(\mathbf{15\;\text{y}\; 16}\) (\(15 \times 16 = 240\)).
Ejercicio 10 — Teorema de Pitágoras

En un triángulo rectángulo, la hipotenusa mide \(13\text{ cm}\) y uno de los catetos mide \(7\text{ cm}\) más que el otro cateto. Calcula la longitud de ambos catetos.

Modelación y solución:
• Cateto menor \(= x\); cateto mayor \(= x + 7\); hipotenusa \(= 13\).
• Teorema de Pitágoras: \(x^2 + (x + 7)^2 = 13^2 \implies x^2 + x^2 + 14x + 49 = 169\)
• \(2x^2 + 14x - 120 = 0 \implies x^2 + 7x - 60 = 0 \implies (x + 12)(x - 5) = 0 \implies x = 5\).
• Respuesta: \(\mathbf{\text{Catetos de 5 cm y 12 cm}}\) (\(5^2 + 12^2 = 25 + 144 = 169 = 13^2\)).
Ejercicio 11 — Marco de Fotografía (Geometría)

Una fotografía de \(10\text{ cm}\) por \(15\text{ cm}\) se coloca dentro de un marco de ancho uniforme \(x\). Si el área total (fotografía más marco) es de \(266\text{ cm}^2\), determina el ancho \(x\) del marco.

Modelación y solución:
• Dimensiones exteriores: ancho \(= 10 + 2x\); largo \(= 15 + 2x\).
• Ecuación: \((10 + 2x)(15 + 2x) = 266 \implies 150 + 50x + 4x^2 = 266\)
• \(4x^2 + 50x - 116 = 0 \implies 2x^2 + 25x - 58 = 0 \implies (2x + 29)(x - 2) = 0\).
• Descartamos \(x = -14.5\); el ancho uniforme es \(\mathbf{x = 2\text{ cm}}\) (\(14 \times 19 = 266\text{ cm}^2\)).
Ejercicio 12 — Lanzamiento Vertical (Física)

Se lanza un proyectil verticalmente hacia arriba y su altura \(h\) (en metros) después de \(t\) segundos está dada por \(h(t) = -5t^2 + 30t\). ¿En qué instantes de tiempo el proyectil se encuentra a una altura de \(40\text{ metros}\)?

Modelación y solución:
• Igualamos \(h(t) = 40\): \(-5t^2 + 30t = 40 \implies 5t^2 - 30t + 40 = 0\)
• Dividimos entre \(5\): \(t^2 - 6t + 8 = 0 \implies (t - 2)(t - 4) = 0 \implies t_1 = 2,\; t_2 = 4\).
• Interpretación física: Alcanza los \(40\text{ m}\) a los \(\mathbf{2\text{ segundos}}\) (cuando va subiendo) y nuevamente a los \(\mathbf{4\text{ segundos}}\) (cuando va descendiendo).

4. Preguntas de Reflexión Crítica

Análisis conceptual sobre métodos de resolución, raíces negativas y naturaleza del discriminante.

1. ¿Cuándo conviene elegir cada método de resolución?

Compara las cuatro estrategias estudiadas (despeje directo, factorización, completación de cuadrados y fórmula general). ¿Por qué intentar factorizar una ecuación con discriminante \(\Delta = 37\) (como en el Ejercicio 6) es una pérdida de tiempo en los números enteros, y cómo el discriminante te avisa de antemano si un trinomio es factorizable con coeficientes enteros?

2. El error de dividir ambos miembros entre la incógnita \(x\)

Al resolver \(5x^2 + 15x = 0\), un estudiante divide toda la ecuación entre \(x\) y obtiene \(5x + 15 = 0 \implies x = -3\). Explica qué solución perdió en el camino y por qué nunca debe dividirse una ecuación entre una expresión que contiene la variable sin analizar primero el caso en que esa expresión vale cero.

3. Pertinencia de las dos raíces en problemas aplicados

Contrasta el Ejemplo 4 (dimensiones de un terreno, donde se rechaza \(x = -16\)) con el Ejercicio 12 (altura de un proyectil, donde ambas soluciones \(t = 2\text{ s}\) y \(t = 4\text{ s}\) son válidas). Explica por qué en las aplicaciones cuadráticas siempre deben evaluarse ambas raíces frente al dominio físico del problema.

4. Reconstrucción de una ecuación a partir de sus raíces (Vieta)

Si sabes que una ecuación cuadrática mónica (\(a = 1\)) tiene como soluciones \(x_1 = 5\) y \(x_2 = -3\), ¿cómo puedes escribir directamente su ecuación estándar \(x^2 - Sx + P = 0\) usando la suma \(S = x_1 + x_2\) y el producto \(P = x_1 \cdot x_2\) de sus raíces?

5. Evaluación Formativa

Comprobación de dominio en factorización, completación de cuadrados, fórmula general, discriminante y modelación.

Ítem 1 — Resolución por Factorización

Resuelve por factorización y comprueba ambas raíces: \(\;4x^2 - 12x + 9 = 0\)

Solución:
• Reconocemos un Trinomio Cuadrado Perfecto: \((2x - 3)^2 = 0\).
• Raíz doble: \(2x - 3 = 0 \implies \mathbf{x_1 = x_2 = \dfrac{3}{2}}\) (\(\Delta = (-12)^2 - 4(4)(9) = 0\)).
Ítem 2 — Completación de Cuadrados

Resuelve completando el cuadrado: \(\;x^2 + 10x + 21 = 0\)

Solución:
• \(x^2 + 10x = -21 \implies x^2 + 10x + 25 = -21 + 25 \implies (x + 5)^2 = 4\)
• \(x + 5 = \pm 2 \implies \mathbf{x_1 = -3,\quad x_2 = -7}\).
Ítem 3 — Discriminante y Fórmula General

Calcula el discriminante de \(2x^2 + 3x + 5 = 0\) e indica cuántas soluciones reales posee la ecuación. Justifica tu respuesta.

Solución:
• \(a = 2,\; b = 3,\; c = 5 \implies \Delta = 3^2 - 4(2)(5) = 9 - 40 = \mathbf{-31}\).
• Como \(\Delta < 0\), la raíz cuadrada \(\sqrt{-31}\) no está definida en los números reales; por tanto, la ecuación \(\mathbf{\text{no tiene soluciones reales}}\).
Ítem 4 — Problema de Aplicación Integrador

Con una lámina cuadrada de cartón se construye una caja abierta cortando cuadrados de \(3\text{ cm}\) de lado en cada esquina y doblando los bordes. Si el volumen de la caja es de \(192\text{ cm}^3\), determina las dimensiones originales de la lámina cuadrada.

Modelación, resolución e interpretación:
• Sea \(x\) el lado original de la lámina (en cm). Al cortar \(3\text{ cm}\) en cada extremo, la base cuadrada de la caja mide \((x - 6)\text{ cm}\) por lado y su altura es \(3\text{ cm}\).
• Volumen (\(V = \text{base} \times \text{altura}\)): \(3(x - 6)^2 = 192 \implies (x - 6)^2 = 64\)
• \(x - 6 = \pm 8 \implies x_1 = 14,\; x_2 = -2\) (descartada).
• Respuesta: La lámina original medía \(\mathbf{14\text{ cm} \times 14\text{ cm}}\) (\(3 \times 8^2 = 3 \times 64 = 192\text{ cm}^3\)).
