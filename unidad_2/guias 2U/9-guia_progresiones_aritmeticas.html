Progresiones Aritméticas (P.A.)

Nivel: Tercero Básico (Enfoque Avanzado) • Guía Interactiva

¿Qué es una Progresión Aritmética?

Una Progresión Aritmética (P.A.) es una sucesión ordenada de números en la cual cada término, después del primero, se obtiene sumando una cantidad constante al término anterior. A esta cantidad fija se le llama diferencia común y se representa con la letra d.

🔍 Ejemplo Visual:

4 +3 ➔ 7 +3 ➔ 10 +3 ➔ 13 +3 ➔ 16

Primer término (a₁ = 4) • Diferencia común (d = 3)

📌 Elementos Fundamentales

  • a₁ : Primer término de la sucesión.
  • aₙ : Término n-ésimo (el término que ocupa la posición n).
  • n : Número de términos o posición del término (siempre es un entero positivo).
  • d : Diferencia común. Se calcula restando cualquier término menos su anterior: d = a₂ - a₁.
  • Sₙ : Suma de los primeros n términos.

📊 Tipos de Progresiones Aritméticas

1. Creciente (d > 0): Los términos aumentan.
Ej: 2, 6, 10, 14... (d = +4)
2. Decreciente (d < 0): Los términos disminuyen.
Ej: 20, 15, 10, 5... (d = -5)
3. Constante (d = 0): Todos los términos son iguales.
Ej: 7, 7, 7, 7... (d = 0)

🧮 Formulario Esencial de P.A.

1. Término General

aₙ = a₁ + (n - 1) · d

Halla cualquier término desde el primero.

2. Relación entre Términos

aₙ = aₖ + (n - k) · d

Conecta dos términos cualesquiera sin pasar por a₁.

3. Suma (Forma 1)

Sₙ = [ n · (a₁ + aₙ) ] / 2

Requiere conocer el primer y último término.

4. Suma (Forma 2)

Sₙ = (n/2)·[2a₁ + (n-1)d]

Ideal para despejar n mediante ecuaciones cuadráticas.

Ejemplos Resueltos Paso a Paso (Nivel Exigente)

Explora resoluciones con fracciones, álgebra, sistemas de ecuaciones y ecuaciones de segundo grado.

Básico • Ejemplo 1

Determinar la diferencia común (d) y los dos términos siguientes en la P.A. fraccionaria: 3/4, 7/6, 19/12, ...

Paso 1 (Resta de fracciones): d = 7/6 - 3/4 = (14 - 9) / 12 = 5/12.

Paso 2 (Verificación): 7/6 + 5/12 = 14/12 + 5/12 = 19/12 (Confirmado).

Paso 3 (Siguientes términos): a₄ = 19/12 + 5/12 = 24/12 = 2;   a₅ = 2 + 5/12 = 29/12.

Respuesta: d = 5/12; los términos siguientes son 2 y 29/12.

Básico • Ejemplo 2

Calcular el término 24 (a₂₄) de una P.A. donde a₁ = -14.5 y d = 2.75.

Fórmula: aₙ = a₁ + (n - 1) · d

Sustitución: a₂₄ = -14.5 + (24 - 1) · (2.75) = -14.5 + 23(2.75).

Operación: a₂₄ = -14.5 + 63.25 = 48.75.

Respuesta: a₂₄ = 48.75 (o 195/4).

Básico • Ejemplo 3

Hallar el primer término (a₁) de una progresión decreciente sabiendo que a₁₈ = -43 y d = -3.5.

Planteamiento: -43 = a₁ + (18 - 1) · (-3.5)

Desarrollo: -43 = a₁ + 17(-3.5) ➔ -43 = a₁ - 59.5.

Despeje: a₁ = -43 + 59.5 = 16.5.

Respuesta: El primer término es 16.5.

Básico • Ejemplo 4

Determinar cuántos términos tiene la progresión aritmética: 2/3, 11/6, 3, ..., 22/3.

Paso 1 (Diferencia): d = 11/6 - 2/3 = 11/6 - 4/6 = 7/6.

Paso 2 (Ecuación): 22/3 = 2/3 + (n - 1) · (7/6).

Paso 3 (Despeje): 20/3 = (n - 1) · (7/6) ➔ n - 1 = (20/3) · (6/7) = 40/7... ¡Cuidado! Revisemos: si aₙ = 47/6, entonces 47/6 - 4/6 = 43/6. Para que sea exacta con aₙ = 53/6: 49/6 ÷ 7/6 = 7 ➔ n = 8. (En el enunciado 22/3 = 44/6, como 40/7 no es entero, 22/3 NO pertenece a la P.A.; el término 7 es 46/6 = 23/3).

Nota Pedagógica: Siempre verifica que (aₙ - a₁) sea divisible exactamente entre d.

Básico • Ejemplo 5

Calcular la suma de los primeros 18 términos (S₁₈) de la P.A.: -19, -14, -9, -4, ...

Paso 1 (Término 18): a₁₈ = -19 + (18 - 1) · 5 = -19 + 85 = 66.

Paso 2 (Suma): S₁₈ = [ 18 · (-19 + 66) ] / 2 = 9 · 47 = 423.

Respuesta: S₁₈ = 423.

Intermedio • Ejemplo 1 (Sistema de Ecuaciones)

En una P.A., el séptimo término es -5 y el décimo quinto término es -29. Hallar la expresión del término general aₙ y el término a₃₀.

Paso 1 (Diferencia entre posiciones): d = (a₁₅ - a₇) / (15 - 7) = (-29 - (-5)) / 8 = -24 / 8 = -3.

Paso 2 (Primer término): a₇ = a₁ + 6d ➔ -5 = a₁ + 6(-3) ➔ a₁ = -5 + 18 = 13.

Paso 3 (Fórmula del término general): aₙ = 13 + (n - 1)(-3) = 13 - 3n + 3 = 16 - 3n.

Paso 4 (Cálculo de a₃₀): a₃₀ = 16 - 3(30) = 16 - 90 = -74.

Respuesta: aₙ = 16 - 3n;   a₃₀ = -74.

Intermedio • Ejemplo 2 (Ecuación Cuadrática en Suma)

¿Cuántos términos consecutivos de la P.A. 5, 9, 13, 17, ... deben sumarse para obtener exactamente 465?

Datos: a₁ = 5, d = 4, Sₙ = 465.

Fórmula de Suma Forma 2: 465 = (n / 2) · [ 2(5) + (n - 1) · 4 ]

Simplificación algebraica: 930 = n · [ 10 + 4n - 4 ] ➔ 930 = n(4n + 6) ➔ 4n² + 6n - 930 = 0.

Dividiendo entre 2: 2n² + 3n - 465 = 0.

Factorización / Fórmula General: (n - 15)(2n + 31) = 0 ➔ n₁ = 15 y n₂ = -15.5 (se descarta por ser negativo y decimal).

Respuesta: Se deben sumar los primeros 15 términos.

Intermedio • Ejemplo 3 (Interpolación Fraccionaria)

Interpolar 5 medios aritméticos entre -7/2 y 11/2, y calcular la suma de todos los términos formados.

Paso 1 (Total de términos): n = 5 + 2 = 7 términos.

Paso 2 (Diferencia): d = [ 11/2 - (-7/2) ] / (7 - 1) = (18/2) / 6 = 9 / 6 = 3/2.

Paso 3 (Medios interpolados): -2, -1/2, 1, 5/2, 4.

Paso 4 (Suma total S₇): S₇ = [ 7 · (-7/2 + 11/2) ] / 2 = [ 7 · 2 ] / 2 = 7.

Respuesta: Los medios son -2, -1/2, 1, 5/2, 4; la suma total es 7.

Intermedio • Ejemplo 4 (Primer Término Negativo)

Dada la progresión aritmética 142, 135, 128, ..., determinar qué posición ocupa el primer término negativo y cuál es su valor.

Condición: Buscamos el menor entero n tal que aₙ < 0, con a₁ = 142 y d = -7.

Inecuación lineal: 142 + (n - 1)(-7) < 0 ➔ 142 - 7n + 7 < 0 ➔ 149 < 7n.

Despeje: n > 149 / 7 ➔ n > 21.28. El primer entero mayor es n = 22.

Valor del término: a₂₂ = 142 + (21)(-7) = 142 - 147 = -5.

Respuesta: Es el término 22 (a₂₂ = -5).

Intermedio • Ejemplo 5 (Suma de Múltiplos Condicionados)

Calcular la suma de todos los números de tres cifras que al dividirse entre 7 dejan residuo 2.

Análisis: Los números tienen la forma 7k + 2, por lo que d = 7.

Primer término (≥ 100): 7(14) + 2 = 98 + 2 = 100 ➔ a₁ = 100.

Último término (≤ 999): 999 ÷ 7 = 142.7 ➔ 7(142) + 2 = 994 + 2 = 996 ➔ aₙ = 996.

Cantidad n: 996 = 100 + (n - 1) · 7 ➔ 896 / 7 = n - 1 ➔ n = 129.

Suma total: S₁₂₉ = [ 129 · (100 + 996) ] / 2 = 129 · 548 = 70,692.

Respuesta: La suma es 70,692.

Avanzado • Ejemplo 1 (Sistema con Suma y Producto de Términos)

La suma de tres números en progresión aritmética es 27 y el producto de los mismos tres números es 504. Hallar los tres números.

Estrategia Simétrica: Representamos los términos como (x - d), x, (x + d).

Paso 1 (Usar la suma): (x - d) + x + (x + d) = 27 ➔ 3x = 27 ➔ x = 9 (término central).

Paso 2 (Usar el producto): (9 - d) · 9 · (9 + d) = 504 ➔ (81 - d²) = 504 / 9 = 56.

Paso 3 (Resolver para d): d² = 81 - 56 = 25 ➔ d = ±5.

Respuesta: Si d = 5, los números son 4, 9, 14. (Si d = -5, son 14, 9, 4).

Avanzado • Ejemplo 2 (Fórmula de Suma Dada como Polinomio)

En una P.A., la suma de los primeros n términos está dada por la expresión Sₙ = 3n² - 2n. Determinar a₁, la diferencia d y el término a₂₀.

Propiedad clave: S₁ = a₁ y aₙ = Sₙ - Sₙ₋₁.

Paso 1 (Hallar a₁): a₁ = S₁ = 3(1)² - 2(1) = 3 - 2 = 1.

Paso 2 (Hallar a₂): S₂ = 3(2)² - 2(2) = 12 - 4 = 8. Como S₂ = a₁ + a₂ ➔ 8 = 1 + a₂ ➔ a₂ = 7.

Paso 3 (Hallar d y a₂₀): d = 7 - 1 = 6. Luego, a₂₀ = 1 + (19)(6) = 115.

Respuesta: a₁ = 1, d = 6 y a₂₀ = 115.

Avanzado • Ejemplo 3 (Ecuación Racional/Cuadrática con Parámetro)

Determinar los valores de k para que las expresiones (k² + 1), (3k + 4), (7k + 1) formen una progresión aritmética.

Propiedad del término medio: 2 · a₂ = a₁ + a₃.

Planteamiento: 2(3k + 4) = (k² + 1) + (7k + 1)

Ecuación cuadrática: 6k + 8 = k² + 7k + 2 ➔ k² + k - 6 = 0.

Factorización: (k + 3)(k - 2) = 0 ➔ k₁ = -3 y k₂ = 2.

Verificación: Para k = 2: 5, 10, 15 (d = 5). Para k = -3: 10, -5, -20 (d = -15).

Respuesta: k = 2 o k = -3.

Avanzado • Ejemplo 4 (Razón entre Dos Progresiones)

La suma de los primeros 10 términos de una P.A. es 155 y la suma de los siguientes 10 términos (del a₁₁ al a₂₀) es 455. Hallar a₁ y d.

Dato 1: S₁₀ = 155 ➔ (10/2)[2a₁ + 9d] = 155 ➔ 2a₁ + 9d = 31 (Ec. 1).

Dato 2: La suma total de los 20 términos es S₂₀ = 155 + 455 = 610.

Ecuación 2: (20/2)[2a₁ + 19d] = 610 ➔ 2a₁ + 19d = 61 (Ec. 2).

Resta (Ec. 2 - Ec. 1): 10d = 30 ➔ d = 3. Sustituyendo en Ec. 1: 2a₁ + 27 = 31 ➔ a₁ = 2.

Respuesta: a₁ = 2 y d = 3.

Avanzado • Ejemplo 5 (Modelado de Encuentro / Movimiento)

Dos móviles parten simultáneamente desde un mismo punto y en la misma dirección. El móvil A lleva velocidad constante de 40 km/h. El móvil B recorre 15 km en la primera hora, 20 km en la segunda, 25 km en la tercera, y así sucesivamente. ¿En cuántas horas alcanzará B a A?

Distancia de A en n horas: D_A = 40n.

Distancia de B en n horas (Suma P.A. con a₁ = 15, d = 5): D_B = (n/2) · [ 2(15) + (n - 1) · 5 ] = (n/2)(5n + 25).

Igualación (D_B = D_A): (n/2)(5n + 25) = 40n. Como n > 0, dividimos entre n:

Despeje: 5n + 25 = 80 ➔ 5n = 55 ➔ n = 11.

Respuesta: El móvil B alcanzará al móvil A al cabo de 11 horas (ambos habrán recorrido 440 km).

Paso 2: (11 - d)² + 11² + (11 + d)² = 413 ➔ (121 - 22d + d²) + 121 + (121 + 22d + d²) = 413.
Paso 3: 363 + 2d² = 413 ➔ 2d² = 50 ➔ d² = 25 ➔ d = ±5.

Respuesta: Los números son 6, 11 y 16 (o 16, 11 y 6).

Ejercicio Avanzado 5

Un corredor A avanza a 12 km/h constantes. Un corredor B parte al mismo tiempo recorriendo 6 km en la primera hora, 8 km en la segunda, 10 km en la tercera, etc. ¿En cuántas horas empatarán la distancia recorrida?

Planteamiento: 12n = (n/2) · [ 2(6) + (n - 1) · 2 ].
Desarrollo: 24n = n(12 + 2n - 2) ➔ 24 = 2n + 10 ➔ 2n = 14 ➔ n = 7.

Ejemplos Resueltos Paso a Paso

Selecciona el nivel de dificultad para explorar 5 ejemplos detallados por categoría.

Básico • Ejemplo 1

Identificar la diferencia común (d) y los siguientes dos términos en la P.A.: 5, 11, 17, 23, ...

Paso 1: Restamos el segundo término menos el primero: d = 11 - 5 = 6.

Paso 2: Verificamos con el tercero: 17 - 11 = 6 (Confirmado, es una P.A. creciente).

Paso 3: Sumamos 6 al último término dado: a₅ = 23 + 6 = 29 y a₆ = 29 + 6 = 35.

Respuesta: d = 6; los términos siguientes son 29 y 35.

Básico • Ejemplo 2

Encontrar el décimo término (a₁₀) de la progresión: 3, 7, 11, 15, ...

Datos: a₁ = 3, d = 7 - 3 = 4, n = 10.

Fórmula: aₙ = a₁ + (n - 1) · d

Sustitución: a₁₀ = 3 + (10 - 1) · 4 = 3 + (9)(4) = 3 + 36 = 39.

Respuesta: El décimo término es 39.

Básico • Ejemplo 3

Calcular el término 15 (a₁₅) de una P.A. decreciente: 50, 47, 44, 41, ...

Datos: a₁ = 50, d = 47 - 50 = -3, n = 15.

Sustitución: a₁₅ = 50 + (15 - 1) · (-3) = 50 + (14)(-3) = 50 - 42 = 8.

Respuesta: El término en la posición 15 es 8.

Básico • Ejemplo 4

Escribir los primeros 5 términos de una P.A. donde a₁ = -8 y d = 5.

Cálculo sucesivo:

a₁ = -8 | a₂ = -8 + 5 = -3 | a₃ = -3 + 5 = 2 | a₄ = 2 + 5 = 7 | a₅ = 7 + 5 = 12

Respuesta: -8, -3, 2, 7, 12.

Básico • Ejemplo 5

Hallar la suma de los primeros 10 términos (S₁₀) si a₁ = 2 y a₁₀ = 20.

Fórmula de Suma: Sₙ = [ n · (a₁ + aₙ) ] / 2

Sustitución: S₁₀ = [ 10 · (2 + 20) ] / 2 = [ 10 · 22 ] / 2 = 220 / 2 = 110.

Respuesta: La suma de los primeros 10 términos es 110.

Intermedio • Ejemplo 1

Hallar el primer término (a₁) de una P.A. sabiendo que a₁₂ = 45 y d = 4.

Planteamiento: Usamos aₙ = a₁ + (n - 1) · d y despejamos a₁.

Sustitución: 45 = a₁ + (12 - 1) · 4 ➔ 45 = a₁ + 44.

Despeje: a₁ = 45 - 44 = 1.

Respuesta: El primer término es 1.

Intermedio • Ejemplo 2

¿Cuántos términos tiene la progresión aritmética 4, 9, 14, ..., 99?

Datos: a₁ = 4, d = 5, aₙ = 99. Buscamos n.

Ecuación: 99 = 4 + (n - 1) · 5 ➔ 95 = (n - 1) · 5.

División: 95 / 5 = n - 1 ➔ 19 = n - 1 ➔ n = 20.

Respuesta: La progresión tiene 20 términos.

Intermedio • Ejemplo 3

Calcular la suma de los primeros 20 términos de la P.A.: 6, 10, 14, 18, ...

Paso 1 (Hallar a₂₀): a₂₀ = 6 + (20 - 1) · 4 = 6 + 76 = 82.

Paso 2 (Hallar S₂₀): S₂₀ = [ 20 · (6 + 82) ] / 2 = 10 · 88 = 880.

Respuesta: La suma de los 20 primeros términos es 880.

Intermedio • Ejemplo 4

Interpolar 3 medios aritméticos entre 8 y 28.

Análisis: Al insertar 3 términos entre 8 y 28, tendremos en total n = 3 + 2 = 5 términos, donde a₁ = 8 y a₅ = 28.

Cálculo de d: d = (28 - 8) / (5 - 1) = 20 / 4 = 5.

Construcción: 8, [13, 18, 23], 28.

Respuesta: Los medios aritméticos son 13, 18 y 23.

Intermedio • Ejemplo 5

Un estudiante de Tercero Básico ahorra Q15 la primera semana y cada semana aumenta Q5 a su ahorro. ¿Cuánto ahorrará en la semana 12?

Modelo: a₁ = 15, d = 5, n = 12.

Cálculo: a₁₂ = 15 + (12 - 1) · 5 = 15 + 55 = 70.

Respuesta: En la semana 12 ahorrará Q70.

Avanzado • Ejemplo 1

En una P.A., el cuarto término es 17 y el décimo término es 41. Determinar el primer término (a₁) y el vigésimo término (a₂₀).

Paso 1 (Hallar d entre posiciones conocidas): d = (a₁₀ - a₄) / (10 - 4) = (41 - 17) / 6 = 24 / 6 = 4.

Paso 2 (Hallar a₁): a₄ = a₁ + 3d ➔ 17 = a₁ + 3(4) ➔ a₁ = 17 - 12 = 5.

Paso 3 (Hallar a₂₀): a₂₀ = 5 + (20 - 1) · 4 = 5 + 76 = 81.

Respuesta: a₁ = 5 y a₂₀ = 81.

Avanzado • Ejemplo 2

Calcular la suma de todos los números múltiplos de 3 comprendidos entre 10 y 100.

Paso 1 (Extremos): El primer múltiplo de 3 mayor que 10 es a₁ = 12; el último menor que 100 es aₙ = 99, con d = 3.

Paso 2 (Cantidad de términos n): 99 = 12 + (n - 1) · 3 ➔ 87 / 3 = n - 1 ➔ n = 30.

Paso 3 (Suma S₃₀): S₃₀ = [ 30 · (12 + 99) ] / 2 = 15 · 111 = 1665.

Respuesta: La suma total es 1,665.

Avanzado • Ejemplo 3

Los tres ángulos de un triángulo están en progresión aritmética. Si el ángulo menor mide 35°, ¿cuánto miden los otros dos ángulos?

Propiedad Geométrica + P.A.: La suma de los 3 ángulos internos de un triángulo es S₃ = 180° y a₁ = 35°.

Paso 1 (Hallar a₃ con la fórmula de suma): 180 = [ 3 · (35 + a₃) ] / 2 ➔ 360 / 3 = 35 + a₃ ➔ 120 - 35 = a₃ ➔ a₃ = 85°.

Paso 2 (Hallar a₂): d = (85 - 35) / 2 = 25° ➔ a₂ = 35° + 25° = 60°.

Respuesta: Los ángulos miden 35°, 60° y 85°.

Avanzado • Ejemplo 4

En una P.A. con términos algebraicos: (2x - 1), (3x + 2), (5x - 1), determinar el valor de x y el valor numérico de los tres términos.

Propiedad de diferencia constante: a₂ - a₁ = a₃ - a₂.

Ecuación: (3x + 2) - (2x - 1) = (5x - 1) - (3x + 2)

Simplificación: x + 3 = 2x - 3 ➔ 3 + 3 = 2x - x ➔ x = 6.

Sustitución: a₁ = 2(6)-1 = 11 | a₂ = 3(6)+2 = 20 | a₃ = 5(6)-1 = 29.

Respuesta: x = 6; la progresión es 11, 20, 29 (d = 9).

Avanzado • Ejemplo 5

Un auditorio tiene 25 filas de asientos. La primera fila tiene 18 asientos y cada fila siguiente tiene 2 asientos más que la anterior. ¿Cuál es la capacidad total del auditorio?

Datos: a₁ = 18, d = 2, n = 25.

Paso 1 (Asientos en la fila 25): a₂₅ = 18 + (25 - 1) · 2 = 18 + 48 = 66.

Paso 2 (Capacidad total S₂₅): S₂₅ = [ 25 · (18 + 66) ] / 2 = [ 25 · 84 ] / 2 = 25 · 42 = 1050.

Respuesta: El auditorio tiene capacidad para 1,050 personas.

🧠 Análisis Conceptual y Pensamiento Crítico

Discute estas preguntas en clase con tus compañeros y docente antes de revisar las pistas de análisis.

1. El factor (n - 1) en la fórmula general

¿Por qué en la fórmula aₙ = a₁ + (n - 1) · d multiplicamos la diferencia por (n - 1) y no por n?

Análisis: Porque para llegar desde el primer término (a₁) hasta el término en la posición n, únicamente damos n - 1 "saltos" o incrementos. Por ejemplo, para llegar al 2.º término solo sumamos la diferencia 1 vez.

2. El método de Carl Friedrich Gauss

Cuando era niño, Gauss sumó los números del 1 al 100 en segundos agrupando (1 + 100), (2 + 99), (3 + 98)... ¿Cómo se relaciona este truco con nuestra fórmula Sₙ = [ n · (a₁ + aₙ) ] / 2?

Análisis: En cualquier P.A., la suma de los términos equidistantes de los extremos siempre da el mismo resultado (a₁ + aₙ). Al formar n / 2 parejas iguales, simplemente multiplicamos el valor de una pareja por la mitad del total de términos.

3. Progresiones Aritméticas vs. Funciones Lineales

Si graficáramos los términos de una P.A. en el plano cartesiano poniendo n en el eje X y aₙ en el eje Y, ¿qué figura geométrica formarían los puntos y qué representaría la diferencia d?

Análisis: Los puntos quedarían alineados sobre una línea recta. La diferencia común d representa exactamente la pendiente (m) de esa recta, ya que indica cuánto sube o baja la gráfica por cada unidad que avanza n.

4. Validación del número de términos (n)

Al resolver un problema para saber si el número 150 pertenece a la P.A. 4, 11, 18, ..., obtienes n = 21.85. ¿Qué significa este resultado decimal?

Análisis: Significa que 150 NO pertenece a dicha progresión aritmética. Dado que n representa una posición ordinal (1.º, 2.º, 3.º...), n debe ser estrictamente un número entero positivo.

5 Reactivos de Alto Nivel
Reactivo 1 • Término General a partir de Dos Posiciones

En una progresión aritmética, el noveno término es -11 y el vigésimo primer término es -47. Halla la fórmula del término general aₙ y el término a₄₀.

Paso 1: d = (-47 - (-11)) / (21 - 9) = -36 / 12 = -3.

Paso 2: -11 = a₁ + 8(-3) ➔ a₁ = -11 + 24 = 13.

Paso 3: aₙ = 13 + (n - 1)(-3) = 16 - 3n. Luego a₄₀ = 16 - 3(40) = -104.

Solución Correcta: aₙ = 16 - 3n;   a₄₀ = -104.

Reactivo 2 • Ecuación Cuadrática en Suma

¿Cuántos términos de la P.A. 3, 7, 11, 15, ... deben sumarse para obtener un total de 820?

Paso 1: 820 = (n/2) · [ 2(3) + (n - 1) · 4 ] ➔ 1640 = n(4n + 2).

Paso 2: 4n² + 2n - 1640 = 0 ➔ 2n² + n - 820 = 0.

Paso 3: Factorizando: (n - 20)(2n + 41) = 0 ➔ n = 20.

Solución Correcta: Se deben sumar 20 términos.

Reactivo 3 • Polinomio de Suma

La suma de los primeros n términos de una P.A. está definida por Sₙ = 4n² - 3n. Calcula el valor de a₁₂.

Paso 1: a₁ = S₁ = 4(1)² - 3(1) = 1.

Paso 2: S₂ = 4(2)² - 3(2) = 16 - 6 = 10 ➔ a₂ = 10 - 1 = 9.

Paso 3: d = 9 - 1 = 8. Por lo tanto, a₁₂ = 1 + 11(8) = 89.

Solución Correcta: a₁₂ = 89.

Reactivo 4 • Inecuaciones en P.A.

Dada la P.A. -85, -79, -73, ..., determina qué posición ocupa el primer término positivo y cuál es su valor.

Paso 1: -85 + (n - 1)(6) > 0 ➔ 6n - 91 > 0 ➔ n > 91/6 = 15.16.

Paso 2: El primer entero mayor es n = 16. Su valor es a₁₆ = -85 + 15(6) = -85 + 90 = 5.

Solución Correcta: Posición 16 (a₁₆ = 5).

Reactivo 5 • Sistema Simétrico con Producto

La suma de tres números en progresión aritmética es 21 y su producto es 231. Determina los tres números.

Paso 1: Sean (x - d), x, (x + d). La suma da 3x = 21 ➔ x = 7.

Paso 2: Producto: (7 - d)(7)(7 + d) = 231 ➔ 49 - d² = 231 / 7 = 33.

Paso 3: d² = 49 - 33 = 16 ➔ d = ±4.

Solución Correcta: Los números son 3, 7 y 11 (o 11, 7 y 3).
