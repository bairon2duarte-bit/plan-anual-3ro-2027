1. Fundamentación Teórica: El Conjunto de los Números Complejos (\(\mathbb{C}\))

La unidad imaginaria \(i\), potencias cíclicas, forma binómica, operaciones fundamentales, conjugado, módulo y plano de Argand.

Unidad Imaginaria (\(i\)) y Raíces Negativas

Definición

En los números reales (\(\mathbb{R}\)), ecuaciones como \(x^2 + 1 = 0\) no tienen solución porque ningún número real al cuadrado es negativo. Para resolverlo se define la unidad imaginaria \(i\):

\[i = \sqrt{-1} \qquad \Longleftrightarrow \qquad i^2 = -1\]

Para todo número real positivo \(a > 0\), la raíz cuadrada principal de \(-a\) se escribe en términos de \(i\):

\[\sqrt{-a} = \sqrt{a \cdot (-1)} = \sqrt{a}\,i \qquad (\text{Ej. } \sqrt{-25} = 5i)\]

Potencias Cíclicas de \(i\) y Forma Binómica

Ciclo de 4

• \(i^1 = i\)

• \(i^2 = -1\)

• \(i^3 = i^2 \cdot i = -i\)

• \(i^4 = (i^2)^2 = (-1)^2 = 1\)

Para calcular \(i^n\) (\(n \in \mathbb{N}\)), se divide \(n\) entre \(4\) y se conserva el residuo \(r\): \(\mathbf{i^n = i^{4q + r} = i^r}\) (con \(i^0 = 1\)).

Forma estándar o binómica: Todo número complejo \(z \in \mathbb{C}\) tiene la forma \(\mathbf{z = a + bi}\), donde \(a = \text{Re}(z)\) es la parte real y \(b = \text{Im}(z)\) es la parte imaginaria (\(a, b \in \mathbb{R}\)).

Operaciones Fundamentales en \(\mathbb{C}\) (Sean \(z_1 = a + bi\) y \(z_2 = c + di\))

Aritmética Compleja

1. Igualdad, Adición y Sustracción

• Igualdad: \(a + bi = c + di \iff a = c \;\text{y}\; b = d\).

• Suma y Resta: Se operan partes reales entre sí y partes imaginarias entre sí:
\((a + bi) \pm (c + di) = (a \pm c) + (b \pm d)i\)

2. Multiplicación y Sustitución \(i^2 = -1\)

Se aplica la propiedad distributiva y se reemplaza \(i^2 = -1\):

\((a + bi)(c + di) = (ac - bd) + (ad + bc)i\)

3. Conjugado Complejo (\(\overline{z}\))

El conjugado de \(z = a + bi\) es \(\overline{z} = a - bi\). Al multiplicar un complejo por su conjugado siempre se obtiene un número real no negativo:

\(z \cdot \overline{z} = (a + bi)(a - bi) = a^2 + b^2\)

4. División de Números Complejos

Se multiplica el numerador y el denominador por el conjugado del denominador para eliminar \(i\) del divisor:

\(\dfrac{a + bi}{c + di} = \dfrac{(a + bi)(c - di)}{c^2 + d^2}\)

Módulo (Valor Absoluto) y Representación Gráfica

Todo número complejo \(z = a + bi\) se representa como el punto \((a, b)\) o vector de posición en el Plano Complejo (Plano de Argand), donde el eje horizontal es el Eje Real (\(\text{Re}\)) y el eje vertical es el Eje Imaginario (\(\text{Im}\)).

Módulo o Norma de \(z = a + bi\)

\[|z| = \sqrt{a^2 + b^2}\]

Representa la distancia euclidiana desde el origen \((0,0)\) hasta el afijo \((a,b)\).

• Real puro: Si \(b = 0 \implies z = a\).  |  Imaginario puro: Si \(a = 0, b \neq 0 \implies z = bi\).

Plano Complejo de Argand: \(z = a + bi\) y su Conjugado \(\overline{z}\)

2. Ejemplos Resueltos Paso a Paso

Simplificación de radicales negativos, potencias de \(i\), operaciones en forma binómica y ecuaciones con soluciones complejas.

Ejemplo 1 — Radicales Negativos y Potencias de \(i\) Simplificación

Simplifique a la forma \(a + bi\): \(\;E = \sqrt{-36} + 3i^{23} - 2i^{42}\)

1. Convertimos el radical negativo: \(\sqrt{-36} = \sqrt{36}\,i = 6i\).

2. Reducimos las potencias de \(i\) dividiendo entre \(4\):
• \(23 = 4(5) + 3 \implies i^{23} = i^3 = -i\)
• \(42 = 4(10) + 2 \implies i^{42} = i^2 = -1\)

3. Sustituimos y ordenamos en forma binómica:
\(E = 6i + 3(-i) - 2(-1) = 6i - 3i + 2 = \mathbf{2 + 3i}\)

Ejemplo 2 — Multiplicación y Binomio al Cuadrado Producto

Efectúe y exprese en forma estándar: \(\;(4 - 3i)(2 + 5i) - (1 - 2i)^2\)

1. Primer producto: \((4 - 3i)(2 + 5i) = 8 + 20i - 6i - 15i^2 = 8 + 14i - 15(-1) = 23 + 14i\).

2. Segundo producto: \((1 - 2i)^2 = 1 - 4i + 4i^2 = 1 - 4i + 4(-1) = -3 - 4i\).

3. Restamos ambos resultados:
\((23 + 14i) - (-3 - 4i) = 23 + 14i + 3 + 4i = \mathbf{26 + 18i}\)

Ejemplo 3 — División de Números Complejos Conjugado

Exprese el cociente \(\dfrac{7 + 4i}{3 - 2i}\) en la forma estándar \(a + bi\).

1. Multiplicamos por el conjugado del denominador \(\dfrac{3 + 2i}{3 + 2i}\):
\(\dfrac{(7 + 4i)(3 + 2i)}{(3 - 2i)(3 + 2i)}\)

2. Desarrollamos numerador y denominador:
• Numerador: \(21 + 14i + 12i + 8i^2 = 21 + 26i - 8 = 13 + 26i\)
• Denominador: \(3^2 + 2^2 = 9 + 4 = 13\)

3. Separamos parte real e imaginaria: \(\dfrac{13 + 26i}{13} = \mathbf{1 + 2i}\)

Ejemplo 4 — Ecuación Cuadrática con Soluciones en \(\mathbb{C}\) Discriminante \(\Delta < 0\)

Resuelve en \(\mathbb{C}\): \(x^2 - 6x + 13 = 0\) y calcula el módulo \(|z|\) de sus raíces.

1. Fórmula general (\(a = 1,\; b = -6,\; c = 13\)):
\(x = \dfrac{6 \pm \sqrt{(-6)^2 - 4(1)(13)}}{2} = \dfrac{6 \pm \sqrt{36 - 52}}{2} = \dfrac{6 \pm \sqrt{-16}}{2}\)

2. Sustituimos \(\sqrt{-16} = 4i\): \(x = \dfrac{6 \pm 4i}{2} \implies \mathbf{x_1 = 3 + 2i,\quad x_2 = 3 - 2i}\).

3. Módulo de ambas raíces conjugadas: \(|z| = \sqrt{3^2 + 2^2} = \mathbf{\sqrt{13}}\).

3. Ejercicios Propuestos por Niveles

Expresa todas tus respuestas en forma binómica estándar \(a + bi\) y verifica cada paso.

Nivel I. Unidad Imaginaria, Potencias de \(i\) y Suma/Resta

Ejercicio 1 — Radicales con Radicando Negativo

Simplifique en términos de \(i\): \(\;\sqrt{-49} + 2\sqrt{-9} - \sqrt{-64}\)

Procedimiento:
• \(7i + 2(3i) - 8i = 7i + 6i - 8i = \mathbf{5i}\) (o \(0 + 5i\)).
Ejercicio 2 — Potencias Sucesivas de \(i\)

Calcule el valor de: \(\;i^{18} + i^{33} - i^{47} + i^{100}\)

Procedimiento (dividiendo exponentes entre \(4\)):
• \(i^{18} = i^2 = -1\);   \(i^{33} = i^1 = i\);   \(i^{47} = i^3 = -i\);   \(i^{100} = i^0 = 1\).
• Sustituimos: \((-1) + i - (-i) + 1 = -1 + i + i + 1 = \mathbf{2i}\).
Ejercicio 3 — Operaciones Combinadas de Suma y Resta

Dados \(z_1 = 5 - 4i\), \(z_2 = -3 + 7i\) y \(z_3 = 2 - 6i\), calcule \(\;2z_1 - z_2 + 3z_3\).

Procedimiento:
• \(2(5 - 4i) - (-3 + 7i) + 3(2 - 6i) = (10 - 8i) + (3 - 7i) + (6 - 18i)\)
• Agrupamos reales e imaginarios: \((10 + 3 + 6) + (-8 - 7 - 18)i = \mathbf{19 - 33i}\).
Ejercicio 4 — Igualdad de Números Complejos

Determine los valores reales de \(x\) e \(y\) que satisfacen la igualdad: \(\;(3x - 2) + (2y + 5)i = 10 - 3i\)

Procedimiento:
• Igualamos partes reales: \(3x - 2 = 10 \implies 3x = 12 \implies \mathbf{x = 4}\).
• Igualamos partes imaginarias: \(2y + 5 = -3 \implies 2y = -8 \implies \mathbf{y = -4}\).

Nivel II. Multiplicación, División y Módulo

Ejercicio 5 — Producto de Binomios Complejos

Efectúe la multiplicación: \(\;(-3 + 4i)(5 - 2i)\)

Procedimiento:
• \(-15 + 6i + 20i - 8i^2 = -15 + 26i - 8(-1) = -15 + 8 + 26i = \mathbf{-7 + 26i}\).
Ejercicio 6 — Cuadrado y Cubo de Complejos

Exprese en forma estándar \(a + bi\): \(\;(2 + 3i)^2 + (1 + i)^3\)

Procedimiento:
• \((2 + 3i)^2 = 4 + 12i + 9i^2 = 4 + 12i - 9 = -5 + 12i\).
• \((1 + i)^3 = 1 + 3i + 3i^2 + i^3 = 1 + 3i - 3 - i = -2 + 2i\).
• Suma total: \((-5 + 12i) + (-2 + 2i) = \mathbf{-7 + 14i}\).
Ejercicio 7 — División de Números Complejos

Calcule el cociente y escríbalo en forma estándar: \(\;\dfrac{5 - 10i}{3 + 4i}\)

Procedimiento:
• Multiplicamos por \(\frac{3 - 4i}{3 - 4i}\): \(\dfrac{(5 - 10i)(3 - 4i)}{3^2 + 4^2} = \dfrac{15 - 20i - 30i + 40i^2}{9 + 16}\)
• \(= \dfrac{15 - 50i - 40}{25} = \dfrac{-25 - 50i}{25} = \mathbf{-1 - 2i}\).
Ejercicio 8 — Inverso Multiplicativo y Módulo

Dado \(z = 6 - 8i\), halle su módulo \(|z|\) y su inverso multiplicativo \(z^{-1} = \dfrac{1}{z}\).

Procedimiento:
• Módulo: \(|z| = \sqrt{6^2 + (-8)^2} = \sqrt{36 + 64} = \sqrt{100} = \mathbf{10}\).
• Inverso: \(z^{-1} = \dfrac{1}{6 - 8i} \cdot \dfrac{6 + 8i}{6 + 8i} = \dfrac{6 + 8i}{100} = \mathbf{\dfrac{3}{50} + \dfrac{2}{25}i}\).

Nivel III. Ecuaciones en \(\mathbb{C}\) y Aplicaciones

Ejercicio 9 — Ecuación Lineal con Coeficientes Complejos

Despeje el número complejo \(z\) en la ecuación: \(\;(2 + i)z + (3 - 4i) = 7 + 3i\)

Procedimiento:
• \((2 + i)z = (7 + 3i) - (3 - 4i) \implies (2 + i)z = 4 + 7i\)
• \(z = \dfrac{4 + 7i}{2 + i} \cdot \dfrac{2 - i}{2 - i} = \dfrac{8 - 4i + 14i - 7i^2}{2^2 + 1^2} = \dfrac{15 + 10i}{5} = \mathbf{3 + 2i}\).
Ejercicio 10 — Ecuación Cuadrática Compleja

Resuelva en el conjunto de los números complejos: \(\;2x^2 + 4x + 5 = 0\)

Procedimiento:
• Fórmula general (\(a = 2,\; b = 4,\; c = 5\)): \(x = \dfrac{-4 \pm \sqrt{4^2 - 4(2)(5)}}{2(2)} = \dfrac{-4 \pm \sqrt{16 - 40}}{4} = \dfrac{-4 \pm \sqrt{-24}}{4}\)
• Como \(\sqrt{-24} = \sqrt{4 \cdot 6}\,i = 2\sqrt{6}\,i\): \(x = \dfrac{-4 \pm 2\sqrt{6}\,i}{4} = \mathbf{-1 \pm \dfrac{\sqrt{6}}{2}i}\).
Ejercicio 11 — Impedancia en Circuitos Eléctricos (Física)

En corriente alterna, la impedancia total \(Z_T\) de dos componentes conectados en paralelo está dada por \(Z_T = \dfrac{Z_1 \cdot Z_2}{Z_1 + Z_2}\). Si \(Z_1 = 4 + 3i\;\Omega\) y \(Z_2 = 4 - 3i\;\Omega\), calcule la impedancia total \(Z_T\).

Modelación y solución:
• Numerador: \(Z_1 \cdot Z_2 = (4 + 3i)(4 - 3i) = 4^2 + 3^2 = 16 + 9 = 25\).
• Denominador: \(Z_1 + Z_2 = (4 + 3i) + (4 - 3i) = 8\).
• Impedancia total: \(Z_T = \dfrac{25}{8} = \mathbf{3.125\;\Omega}\) (impedancia puramente resistiva real).
Ejercicio 12 — Suma de Potencias Consecutivas de \(i\)

Demuestre algebraicamente que la suma de cuatro potencias enteras consecutivas cualesquiera de \(i\) es siempre igual a cero (\(i^n + i^{n+1} + i^{n+2} + i^{n+3} = 0\)), y evalúe \(S = i^1 + i^2 + i^3 + \dots + i^{50}\).

Demostración y evaluación:
• Factorizando \(i^n\): \(i^n(1 + i + i^2 + i^3) = i^n(1 + i - 1 - i) = i^n(0) = \mathbf{0}\).
• En \(S = i^1 + i^2 + \dots + i^{50}\), los primeros \(48\) términos (\(12\) grupos de \(4\)) suman \(0\).
• Solo quedan los últimos dos términos: \(S = i^{49} + i^{50} = i^1 + i^2 = \mathbf{-1 + i}\).

4. Preguntas de Reflexión Crítica

Análisis conceptual sobre la extensión de los sistemas numéricos, propiedades de radicales negativos y conjugados.

1. Falacia de \(\sqrt{-4} \cdot \sqrt{-9} = \sqrt{(-4)(-9)} = \sqrt{36} = 6\)

Un estudiante aplica la propiedad \(\sqrt{a}\sqrt{b} = \sqrt{ab}\) directamente a radicales negativos y afirma que \(\sqrt{-4}\cdot\sqrt{-9} = 6\). Explica por qué dicha propiedad solo es válida cuando \(a \ge 0\) y \(b \ge 0\), y demuestra que el resultado correcto es \((2i)(3i) = 6i^2 = -6\).

2. ¿Por qué \(\mathbb{R}\) es un subconjunto propio de \(\mathbb{C}\) (\(\mathbb{R} \subset \mathbb{C}\))?

Analiza cómo cualquier número real \(a\) (como \(-7\), \(\frac{3}{4}\) o \(\sqrt{2}\)) puede escribirse en la forma \(a + 0i\). ¿Qué ocurre con la relación de orden (\(>\) y \(<\)) al pasar de \(\mathbb{R}\) a \(\mathbb{C}\)? ¿Por qué no tiene sentido afirmar que \(3 + 2i > 1 + 5i\)?

3. Propiedades del Conjugado Complejo (\(\overline{z}\))

Verifica qué ocurre al sumar un número complejo con su conjugado (\(z + \overline{z}\)) y al restarlos (\(z - \overline{z}\)). Explica por qué \(z + \overline{z} = 2\text{Re}(z)\) siempre es un número real puro, y por qué las raíces complejas de ecuaciones cuadráticas con coeficientes reales siempre aparecen en pares conjugados.

4. Efecto geométrico de multiplicar un número complejo por \(i\)

Toma el número complejo \(z = 3 + 2i\) (ubicado en el punto \((3, 2)\) del plano de Argand) y multiplícalo sucesivamente por \(i\) para obtener \(zi = -2 + 3i\), \(zi^2 = -3 - 2i\) y \(zi^3 = 2 - 3i\). Describe qué transformación geométrica (rotación) sufre el vector cada vez que se multiplica por \(i\).

5. Evaluación Formativa

Comprobación de dominio en potencias de \(i\), operaciones en \(\mathbb{C}\), conjugado, módulo y ecuaciones cuadráticas complejas.

Ítem 1 — Potencias de \(i\) y Forma Binómica

Simplifique a la forma \(a + bi\): \(\;Z = 4i^{27} - 3i^{36} + \sqrt{-81}\)

Solución:
• \(i^{27} = i^3 = -i\);   \(i^{36} = i^0 = 1\);   \(\sqrt{-81} = 9i\).
• \(Z = 4(-i) - 3(1) + 9i = -4i - 3 + 9i = \mathbf{-3 + 5i}\).
Ítem 2 — Multiplicación y División

Efectúe y exprese en forma estándar \(a + bi\): \(\;\dfrac{(2 + 3i)(4 - i)}{1 + 2i}\)

Solución:
1. Numerador: \((2 + 3i)(4 - i) = 8 - 2i + 12i - 3i^2 = 11 + 10i\).
2. Dividimos entre \((1 + 2i)\) multiplicando por \(\frac{1 - 2i}{1 - 2i}\):
\(\dfrac{(11 + 10i)(1 - 2i)}{1^2 + 2^2} = \dfrac{11 - 22i + 10i - 20i^2}{5} = \dfrac{31 - 12i}{5} = \mathbf{\dfrac{31}{5} - \dfrac{12}{5}i}\).
Ítem 3 — Módulo y Conjugado

Dado el número complejo \(w = -5 + 12i\), determina su parte real \(\text{Re}(w)\), su parte imaginaria \(\text{Im}(w)\), su conjugado \(\overline{w}\) y su módulo \(|w|\).

Solución:
• \(\text{Re}(w) = \mathbf{-5}\);   \(\text{Im}(w) = \mathbf{12}\);   Conjugado: \(\overline{w} = \mathbf{-5 - 12i}\).
• Módulo: \(|w| = \sqrt{(-5)^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = \mathbf{13}\).
Ítem 4 — Ecuación Cuadrática con Raíces Complejas

Resuelve en \(\mathbb{C}\) la ecuación \(x^2 - 4x + 29 = 0\) y comprueba una de sus soluciones sustituyéndola en la ecuación original.

Solución y comprobación:
• \(x = \dfrac{4 \pm \sqrt{(-4)^2 - 4(1)(29)}}{2} = \dfrac{4 \pm \sqrt{16 - 116}}{2} = \dfrac{4 \pm \sqrt{-100}}{2} = \dfrac{4 \pm 10i}{2}\)
• Raíces: \(\mathbf{x_1 = 2 + 5i,\quad x_2 = 2 - 5i}\).
• Comprobación con \(x_1 = 2 + 5i\): \((2 + 5i)^2 - 4(2 + 5i) + 29 = (4 + 20i - 25) - 8 - 20i + 29 = -21 - 8 + 29 = 0\).
